# ic-lab-init
Initialization (`start.sh`) and deinitialization (`stop.sh`) scripts for my research project using MITRE Caldera (https://github.com/apache/caldera) and its MCP plug-in (https://github.com/mitre/mcp), alongside Velociraptor (https://github.com/Velocidex/velociraptor) and the Windows 10 QEMU/KVM virtual machine on virt-manager.

Test reports are generated manually by each tool's internal functionality.
